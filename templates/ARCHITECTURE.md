## Слои

| Слой | Отвечает за | Не отвечает за |
|---|---|---|
| Данные | хранение, миграции, консистентность | правила бизнеса |
| Бизнес-логика | доменные правила, идемпотентность | HTTP, формат ответа |
| API | контракт, валидация, коды ошибок | доменные правила |
| Представление | UI | правила бизнеса |

Нарушение границы между слоями - главный источник нетестируемости.
